# Ruletas Bíblicas · Libro de Daniel

Funciona **sin internet**: todo está dentro de `index.html` (no descarga nada).

## Instalar en Windows (recomendado, 1 minuto)
1. Descarga/copia esta carpeta completa al computador (ej. `Documentos\Ruletas`).
2. Doble clic en **`Instalar-Windows.bat`**.
3. Aparecen en el Escritorio:
   - **Ruletas Daniel** – ventana de aplicación.
   - **Ruletas Daniel (Proyector)** – directo en pantalla completa.
4. Ábrela y haz clic derecho en su icono de la barra de tareas → **Anclar a la barra de tareas**.

Requiere Microsoft Edge o Google Chrome (ya vienen en Windows). No borres ni muevas la carpeta después de instalar.

## Alternativa: instalar como PWA (si la publicas en internet con https)
Abre la página una vez con internet en Chrome/Edge → icono de instalar en la barra de direcciones
(o el botón "Instalar como aplicación" de la página). Queda guardada y abre sin internet.

## Modo proyector
Botón **⛶ Modo proyector** o tecla **F**. Esc para salir.
La ruleta se agranda y el cronómetro queda a un lado, como una diapositiva.

## Atajos
| Tecla | Acción |
|---|---|
| Espacio | Girar la ruleta |
| C | Iniciar / pausar cronómetro |
| X | Reiniciar cronómetro |
| → / N | Siguiente ronda |
| ← / B | Ronda anterior |
| F / P | Modo proyector |
